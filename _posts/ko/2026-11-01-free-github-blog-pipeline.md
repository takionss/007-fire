**A:** 처음에는 생소할 수 있지만 웹호스팅 세팅의 단골 메뉴이므로 한 번만 해보면 누구나 쉽게 이해할 수 있습니다. 깃허브 설정 메뉴에서 소유하고 있는 **나만의 커스텀 도메인 주소**를 입력하고 DNS 설정에서 CNAME 값만 맞춰주면 주소창이 깔끔하게 변경됩니다. 검색엔진 등록 역시 네이버 웹마스터도구와 구글 서치콘솔에 내 블로그 주소를 등록하고 자동으로 생성된 **사이트맵 파일**을 제출하기만 하면 수일 내에 로봇들이 알아서 글을 긁어갑니다.





### <span style="color: #2980B9;">Q4. 평소에 글을 백업하거나 글의 디자인을 전면적으로 갈아엎고 싶을 때 기존 데이터가 유실될 위험은 없나요?</span>



**A:** 오히려 상용 블로그 플랫폼보다 데이터 유실 위험이 훨씬 적은 편입니다. 본문에 언급된 것처럼 모든 글과 설정 파일은 내 컴퓨터와 깃허브 저장소에 **이중으로 안전하게 보관**되기 때문에 언제든 과거의 특정 시점으로 완벽하게 되돌릴 수 있습니다. 디자인을 완전히 바꾸고 싶을 때는 기존 글 파일들만 그대로 복사해 둔 채 새로운 **오픈소스 테마 저장소**로 갈아끼우기만 하면 되므로, 콘텐츠의 손실 없이 1분 만에 화려한 리뉴얼을 마칠 수 있습니다.
